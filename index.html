Warisan Cita Rasa Autentik

Kampung Dimsum berdiri dengan semangat menghadirkan kelezatan dimsum autentik ke seluruh Indonesia. Berakar dari tradisi kuliner Tionghoa yang kaya, setiap produk kami diracik dari bahan pilihan.

Kini hadir di lebih dari 15 lokasi strategis di Jabodetabek, menjangkau lebih banyak pecinta dimsum di mana pun mereka berada.

Sejarah Kami

Kampung Dimsum lahir dari sebuah ketulusan dan hobi sederhana pada tahun 2021. Berawal dari kreasi dapur rumahan yang ditujukan bagi keluarga, cita rasa unik yang dihasilkan ternyata mendapat apresiasi luar biasa saat mulai dipasarkan secara terbatas melalui kanal digital.

Melihat antusiasme pasar yang terus tumbuh, pada tahun 2022 kami meresmikan kedai pertama kami. Momentum ini menjadi titik tolak transformasi dari usaha rumahan menuju pengelolaan yang lebih profesional.

2021
Lahir dari dapur rumahan — produk perdana dipasarkan via media sosial dan mendapat respons luar biasa.
2022
Kedai pertama resmi dibuka. Transformasi dari usaha rumahan menjadi bisnis kuliner profesional dimulai.
2023 – 2024
Ekspansi pesat — memperkuat fondasi bisnis dengan penambahan titik distribusi di berbagai lokasi strategis Jabodetabek.
2025
Central Kitchen (Rumah Produksi) tersentralisasi mulai beroperasi untuk menjaga standardisasi kualitas di setiap sajian.
2026 — Kini
Lebih dari 15 gerai aktif beroperasi secara mandiri, melayani ribuan pelanggan setiap hari dengan dedikasi yang tidak pernah berubah.
Visi Utama

Menjadi merek kuliner kerakyatan yang paling dipercaya di Indonesia

"Setiap kampung pada waktunya akan menjadi Kampung Dimsum."

Kami percaya bahwa kebahagiaan melalui makanan berkualitas harus dapat dijangkau oleh semua kalangan masyarakat.

Misi & Fokus Strategis
Ekspansi Berkelanjutan

Memperluas jangkauan melalui pembangunan Rumah Produksi di berbagai wilayah strategis untuk memastikan kesegaran produk hingga ke tangan konsumen.

Kemandirian & Integritas

Menjaga keaslian bisnis melalui pengelolaan gerai mandiri guna memastikan kontrol kualitas yang ketat tanpa kompromi.

Inovasi yang Dekat di Hati

Terus berinovasi mengembangkan varian menu yang sesuai dengan selera lokal, namun tetap mengedepankan kebersihan dan nilai gizi tinggi.

Nilai Keunggulan Kami

"Bukan sekadar murah, kami mengedepankan kualitas bahan baku dengan komposisi daging ayam hingga 93%. Melalui pelayanan yang ramah dan sistem operasional yang terintegrasi, kami hadir untuk menghadirkan pengalaman kuliner yang berkesan bagi setiap penikmatnya."

Bahan Baku
Catat pembelian bahan baku Rumah Produksi
Tabel database belum dibuat
Tabel bahan_baku tidak ditemukan di Supabase. Jalankan SQL ini di Supabase → SQL Editor: 
-- Tabel bahan_baku
CREATE TABLE IF NOT EXISTS bahan_baku (
  id BIGSERIAL PRIMARY KEY,
  cabang TEXT NOT NULL,
  tanggal TEXT NOT NULL,
  items JSONB DEFAULT '[]',
  total NUMERIC DEFAULT 0,
  supplier TEXT DEFAULT '',
  catatan TEXT DEFAULT '',
  input_by TEXT DEFAULT '',
  status TEXT DEFAULT 'pending',
  produksi_id BIGINT DEFAULT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE bahan_baku ENABLE ROW LEVEL SECURITY;
CREATE POLICY "allow_all" ON bahan_baku FOR ALL USING (true);

-- Kolom tambahan jika tabel sudah ada
ALTER TABLE bahan_baku ADD COLUMN IF NOT EXISTS status TEXT DEFAULT 'pending';
ALTER TABLE bahan_baku ADD COLUMN IF NOT EXISTS produksi_id BIGINT DEFAULT NULL;

-- Tabel produksi_bb (hasil olah bahan → dimsum)
CREATE TABLE IF NOT EXISTS produksi_bb (
  id BIGSERIAL PRIMARY KEY,
  bahan_baku_id BIGINT REFERENCES bahan_baku(id) ON DELETE SET NULL,
  cabang TEXT NOT NULL,
  tanggal_beli TEXT NOT NULL,
  tanggal_selesai TEXT NOT NULL,
  hasil JSONB DEFAULT '[]',
  total_dimsum INT DEFAULT 0,
  catatan TEXT DEFAULT '',
  selesai_oleh TEXT DEFAULT '',
  created_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE produksi_bb ENABLE ROW LEVEL SECURITY;
CREATE POLICY "public_insert" ON produksi_bb FOR INSERT WITH CHECK (true);
CREATE POLICY "authenticated_all" ON produksi_bb FOR ALL USING (auth.role()='authenticated');
Setelah tabel dibuat, simpan ulang — data akan tersinkronisasi.
